WEBSITE TOKO ABON AYAM MaDiDe Star

CARA PALING MUDAH MENJALANKAN:
1. Ekstrak file ZIP ini ke komputer atau laptop.
2. Buka folder "madide-star-website".
3. Klik dua kali file "index.html".
4. Website akan terbuka di browser (Chrome, Edge, Firefox, dll).

CARA MENJALANKAN DENGAN SERVER LOKAL (OPSIONAL):
1. Pastikan Python sudah terpasang.
2. Buka Terminal / Command Prompt di dalam folder website.
3. Jalankan perintah: python -m http.server 8000
   (Pada sebagian komputer Windows gunakan: py -m http.server 8000)
4. Buka browser dan kunjungi: http://localhost:8000
5. Untuk menghentikan server, kembali ke terminal lalu tekan Ctrl + C.

CARA MENGUBAH INFORMASI:
- Teks, harga, deskripsi, dan tautan: edit file index.html.
- Warna, ukuran, dan tata letak: edit file style.css.
- Interaksi menu: edit file script.js.
- Foto: ganti file di folder assets. Pertahankan nama file agar gambar tetap tampil.
